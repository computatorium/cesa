# cesa
A minimal DokuWiki template.

# usage
Requires DokuWiki 2026-07-14c “Mort” and PHP 8.2+.

Extract [cesa-1.0.0.tar.gz](dist/cesa-1.0.0.tar.gz) into `lib/tpl/`, then select `cesa` in Configuration Manager.
